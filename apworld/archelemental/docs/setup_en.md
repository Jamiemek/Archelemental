# Archelemental Setup Guide

## What you need

- A web browser. The game runs at https://jamiemek.github.io/Archelemental/
- `archelemental.apworld`, from the Archipelago page in the game

## Installing the APWorld

Double-click `archelemental.apworld`, or put it in the `custom_worlds` folder of your Archipelago install.

## Making your options file

Open the Archipelago Launcher, choose "Generate Template Options", and edit `Archelemental.yaml`. There's also an
example in the repository.

## Joining a game

1. Open the game and go to **Archipelago** on the main menu.
2. Type the server address (for example `archipelago.gg:38281`), your slot name and the password if there is one.
3. Press **Connect**.

Each seed and slot keeps its own save on your device, so you can play several at once. The game reconnects by itself
the next time you open it. If you play while disconnected, your checks are sent as soon as it reconnects.

The game is served over https, so browsers will only let it connect to servers that support secure connections.
Rooms on archipelago.gg do. A server on your own computer works as `localhost`.
